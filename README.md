# Nomie Fasting v2

Intermittent fasting: start a fast, see its progress, and log it to Nomie. A widget shows the fast on the dashboard.

Source: https://github.com/RdeLange/nomie-fasting-v2. Pages: https://dailynomie.github.io/nomie-fasting-v2/

## Commands

    npm install
    npm test
    npm run build
